Module State Machine：正常上电与功耗切换主路径

矩形圆角 = Steady State；椭圆 = Transient State
Resetting关闭/清理模块
→
Reset保持复位
→
MgmtInit初始化管理接口
→
ModuleLowPwr基本可管理
升功耗请求
→
ModulePwrUp启动高功耗电路
→
ModuleReady完全可操作
返回低功耗：ModuleReady → ModulePwrDn（Transient）→ ModuleLowPwr。
高优先级路径：除 Reset 状态外，复位请求可使模块转向 Resetting；严重内部故障可进入 ModuleFault。
Steady：等待 Host 或异常事件，持续时间可不受限。　Transient：执行模块控制的活动，通常有完成条件和最大时限。
